# Creative Graphic & Anti-Slop Web Design Suite (v2.0)

Bộ Plugin chuyên sâu dành cho **Google Antigravity**, được thiết kế để xoá bỏ hoàn toàn hội chứng **"Web nhìn na ná nhau"** và **"Mùi AI (AI Slop)"** trong thiết kế đồ hoạ, UI/UX và phát triển trang web.

---

## 📦 Hệ sinh thái 7 Kỹ năng (Skills) bên trong

| STT | Tên Skill | Chức năng cốt lõi |
| :-: | :--- | :--- |
| 1 | **`creative-graphic-design`** | Master skill về Art Direction, bố cục bất đối xứng, tỷ lệ chữ kịch tính, phối màu 60-30-10 và 5 trường phái thẩm mỹ. |
| 2 | **`frontend-design`** | Quy chuẩn thiết kế giao diện chống rập khuôn từ kho `anthropics/skills`, quy trình 2 bước (Lên kế hoạch Visual DNA -> Tự phản biện). |
| 3 | **`anti-template-web-architecture`** | Phá bỏ khung xương SaaS lặp lại (`Hero căn giữa -> 3 cột thẻ -> Bento`). Cung cấp các kiến trúc chuẩn Awwwards/Godly: *Split-Screen Pinned, Editorial Magazine Spread, Interactive Archive Index, Product-as-Hero Sandbox, Broken Grid*. |
| 4 | **`choreographed-motion-ui`** | Đạo diễn chuyển động vật lý với đường cong `cubic-bezier(0.16, 1, 0.3, 1)`, hiệu ứng chữ trồi từ mặt nạ cắt (*Masked Line Reveal*), mở màn ảnh bằng `clip-path`, và tương tác từ tính (*Magnetic UI*). |
| 5 | **`bespoke-visual-craft`** | Cấm dùng "icon trong hộp màu nhạt" (`bg-primary/10`). Thay bằng bản vẽ kỹ thuật SVG nét mảnh (*Technical SVG Schematics*), hạt nhiễu phim *SVG Film Grain*, dấu neo kiến trúc và xử lý ảnh tạp chí. |
| 6 | **`domain-dna-matrix`** | Chống đụng hàng giữa các dự án bằng cách ánh xạ **Hiện vật vật lý của ngành nghề** (bản vẽ CAD, đĩa than, nhãn dược phẩm...) kết hợp **Ma trận phân kỳ 4 trục**. |
| 7 | **`human-editorial-copy`** | Thanh lọc "văn mẫu AI" (*Nâng tầm trải nghiệm, Giải pháp toàn diện, Elevate your workflow*) và cấm bịa số liệu ảo (`99.9%`, `10K+ users`). Viết sắc bén như Biên tập viên thực thụ. |

Đi kèm quy chuẩn thường trực **`rules/AGENTS.md`** luôn tự động kích hoạt trong mọi phiên làm việc.

## 🚀 Cài đặt trên máy mới (1 dòng lệnh)

### Windows (PowerShell):
```powershell
git clone https://github.com/iamkyro/creative-graphic-design.git "$HOME\.gemini\config\plugins\creative-graphic-design"
```

### macOS / Linux:
```bash
git clone https://github.com/iamkyro/creative-graphic-design.git ~/.gemini/config/plugins/creative-graphic-design
```

### Cập nhật phiên bản mới nhất:
```bash
cd ~/.gemini/config/plugins/creative-graphic-design && git pull
```
