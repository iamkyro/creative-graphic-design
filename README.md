# Creative Graphic & Visual Design Plugin

Plugin chuyên biệt dành cho Antigravity AI nhằm nâng cao năng lực thiết kế đồ hoạ thị giác, thoát khỏi hoàn toàn các khuôn mẫu rập khuôn của AI ("AI slop") và các mẫu thiết kế đại trà.

## 📦 Nội dung đóng gói

1. **Skill `creative-graphic-design`**:
   - Master skill về thiết kế đồ hoạ thị giác, poster, banner, visual identity, ấn phẩm truyền thông.
   - Nguyên tắc bố cục bất đối xứng kịch tính, typography nghệ thuật, quản trị màu sắc 60-30-10, chất liệu grain/halftone/risograph.
   - Bộ tài liệu tham khảo các trường phái Art Direction (`references/design-archetypes.md`) và bảng kiểm định 10 câu hỏi chống rập khuôn (`references/anti-cliche-checklist.md`).

2. **Skill `frontend-design`**:
   - Kỹ năng thiết kế giao diện UI/Web kinh điển từ GitHub (`anthropics/skills`), chuyên trị việc loại bỏ các mẫu SaaS cards bo góc 12px vô hồn và màu tím gradient mặc định.

3. **Rule `rules/AGENTS.md`**:
   - Quy chuẩn thường trực tự động kích hoạt giúp AI luôn duy trì tư duy Giám đốc Nghệ thuật (Art Director) trong mọi phản hồi liên quan đến thiết kế.

## 🚀 Cách kích hoạt
- Khởi động lại Antigravity session hoặc IDE để bộ nạp plugin tự động phát hiện thư mục mới.
- Quản lý trạng thái plugin tại trang Customization của hệ thống.
