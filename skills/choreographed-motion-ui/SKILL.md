# Choreographed Motion & Interactive Physics

Một trang web do AI sinh ra thường bị lộ ngay khi người dùng rê chuột hoặc cuộn trang: mọi phần tử đều dùng `transition: all 0.3s ease` hoặc nhấc thẻ lên `transform: translateY(-4px)` một cách máy móc.

Các studio thiết kế hàng đầu sử dụng **Chuyển động có biên đạo (Choreographed Motion)** — nơi tốc độ, gia tốc và độ trễ mang trọng lượng vật lý thực tế.

---

## 1. Hệ thống Đường Cong Gia Tốc Chuẩn Studio (Custom Easing Tokens)

**CẤM** sử dụng `ease`, `ease-in`, `ease-out`, hoặc `linear` cho các chuyển động giao diện chính. Hãy khai báo bộ biến CSS đường cong vật lý sau trong `:root`:

```css
:root {
  /* Phản hồi tức thì, phanh mượt kéo dài — dùng cho Reveal, Modal, Drawer */
  --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);
  
  /* Chuyển động tinh tế, sang trọng — dùng cho Image Scale, Layout Shift */
  --ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);
  
  /* Chuyển động đối xứng kịch tính — dùng cho Page Transition, Tab Switch */
  --ease-in-out-cubic: cubic-bezier(0.65, 0, 0.35, 1);
  
  /* Độ nảy vật lý nhẹ (Spring overshoot) — dùng cho Button, Toggle, Badge */
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

## 2. 5 Kỹ Thuật Biên Đạo Chuyển Động Đỉnh Cao

### A. Masked Line Reveal (Chữ Trồi Lên Từ Mặt Nạ Cắt)
Thay vì làm cả khối chữ mờ dần (`opacity: 0 -> 1` kết hợp `translateY(20px)`) nhìn rất nghiệp dư, hãy bọc từng dòng tiêu đề trong một khung cắt `overflow: hidden` và đẩy chữ từ dưới mặt nạ lên kèm góc nghiêng nhẹ:

```css
.line-mask {
  overflow: hidden;
  display: block;
}

.line-mask > span {
  display: block;
  transform: translateY(110%) rotate(2deg);
  transform-origin: left bottom;
  transition: transform 0.9s var(--ease-out-expo);
}

.is-visible .line-mask > span {
  transform: translateY(0) rotate(0deg);
}
```

### B. Clip-Path Curtain Unveil (Mở Màn Hình Ảnh Nghệ Thuật)
Không bao giờ để hình ảnh chỉ hiện ra bằng `opacity`. Hãy dùng `clip-path` kết hợp thu phóng ngược chiều (`scale(1.15) -> scale(1)`):

```css
.media-reveal {
  clip-path: inset(100% 0 0 0);
  transition: clip-path 1.1s var(--ease-in-out-cubic);
}

.media-reveal img {
  transform: scale(1.18);
  transition: transform 1.4s var(--ease-out-expo);
}

.media-reveal.is-visible {
  clip-path: inset(0% 0 0 0);
}

.media-reveal.is-visible img {
  transform: scale(1);
}
```

### C. Directional Fill & Sliding Text Button (Nút Bấm Cơ Học)
Thay thế kiểu hover đổi màu nền đơn điệu bằng hiệu ứng **trượt lớp nền theo hướng** hoặc **cuộn chữ hai tầng (Dual-layer Text Roll)**:

```css
.btn-kinetic {
  position: relative;
  overflow: hidden;
}

.btn-kinetic::before {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--accent-color);
  transform: scaleY(0);
  transform-origin: bottom;
  transition: transform 0.45s var(--ease-out-expo);
  z-index: 0;
}

.btn-kinetic:hover::before {
  transform: scaleY(1);
  transform-origin: top;
}
```

### D. Interactive Row Dimming (Hiệu Ứng Tiêu Điểm Danh Sách)
Khi có một danh sách dự án hoặc mục thông tin, khi người dùng hover vào 1 mục, hãy làm mờ nhẹ các mục còn lại để tạo tiêu điểm thị giác sắc bén:

```css
.interactive-list:hover .list-item {
  opacity: 0.35;
  transition: opacity 0.4s var(--ease-out-quart), padding 0.4s var(--ease-out-expo);
}

.interactive-list .list-item:hover {
  opacity: 1;
  padding-left: 1.25rem;
}
```

### E. Magnetic & Cursor-Aware Micro-physics (Tương Tác Từ Tính)
Với các nút hành động chính (Primary CTA) hoặc vùng tương tác nghệ thuật, sử dụng một đoạn JavaScript ngắn gọn để tính toán vị trí chuột tương đối so với tâm phần tử, dịch chuyển nhẹ phần tử (`4px - 8px`) hướng về phía con trỏ chuột và trả về vị trí cũ bằng `--ease-spring` khi chuột rời đi.

## 3. Quy Tắc Kỷ Luật Chuyển Động (Motion Restraint)

1. **Một khoảnh khắc đắt giá hơn mười hiệu ứng vụn vặt**: Tập trung năng lượng vào màn chào đầu (Initial Load Sequence) và 1–2 tương tác cốt lõi trên trang.
2. **Không làm chậm người dùng**: Các phản hồi tương tác trực tiếp (hover, click, tab switch) phải bắt đầu ngay lập tức (`0ms delay`) và hoàn tất phần chính trong `200ms - 450ms`.
3. **Tôn trọng Accessibility**: Luôn bọc các chuyển động khoảng cách lớn trong `@media (prefers-reduced-motion: no-preference)`.
